## ADDED Requirements

### Requirement: 未鉴权请求的拒绝语义

服务端 SHALL 对未通过准入的请求返回明确的错误帧，而不是静默断开或当作正常请求处理。
拒绝必须满足：不占用 spool 预算、不触发上游请求、不写入字典缓存、在 stats 里以
`status=401` 记一条、服务端日志能定位到来源连接。

#### Scenario: 拒绝不产生副作用

- **WHEN** 一个未鉴权请求抵达
- **THEN** 服务端不发上游请求、`spool` 里不新增条目、`store` 不新增 body，
  仅在 stats 记一条 401 并在日志留一行

#### Scenario: 客户端能区分「被拒」与「网络故障」

- **WHEN** 客户端收到未授权错误帧
- **THEN** 它把该请求判为 `Fatal`（不续传、不重试），并在日志/提示里明确写「未授权」
